# Golden Dataset v0.1

Base de atividades aprovadas usadas como referência para novas adaptações.

## Estrutura

- `cases.jsonl` — atividades aprovadas no formato JSONL (uma por linha)
- `rubrics.yaml` — critérios de avaliação por tipo de atividade

## Como usar

O sistema usa esses exemplos como benchmarks para:
1. Avaliar qualidade de novas adaptações
2. Calibrar os agentes
3. Comparar versões

## Como contribuir

Quando uma adaptação for aprovada com score máximo, ela pode ser adicionada aqui como exemplo de referência.
