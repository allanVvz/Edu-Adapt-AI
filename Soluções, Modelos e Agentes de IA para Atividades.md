# Soluções, Modelos e Agentes de IA para Atividades Adaptadas em Educação Especial

## 📋 **Modelos de Prompt Prontos para Uso**

### **Prompt 1 - Modelo Completo para Agente de IA**[^1]

```
"Adapte esta atividade para TEA, usando linguagem simples e reduzindo estímulos:
'Complete a palavra BO__ com letras adequadas'."
```


### **Prompt 2 - Simplificação para TEA**[^7]

```
"Adapte esta atividade para TEA usando poucas opções, linguagem clara e fundo visual neutro."
```


### **Prompt 3 - Apoio Visual**[^7]

```
"Transforme esta instrução em uma sequência de 3 passos para aluno com TEA."
```


### **Prompt 4 - Organização Espacial**[^7]

```
"Recrie esta atividade com apresentação visual organizada, separando cada opção em colunas."
```


### **Prompt 5 - Geração de Folha de Atividade**[^2]

```
"Crie uma folha de atividade com esse texto. Use ícones imagens ao lado de cada frase e coloque o texto em caixa alta nessa folha. O tamanho da folha é do A4 pronta para ser impressa."
```


### **Prompt 6 - Planejamento de Jogos (Hiperfoco UNO)**[^8]

```
"Você irá se portar como um professor de Educação Especial, que atua no atendimento educacional especializado de estudantes com deficiências e transtornos, como autismo, discalculia, deficiência intelectual, entre outros. Você atende um estudante que possui hiperfoco em cartas de uno, este estudante apresenta um desempenho ruim na área da matemática. Indique sugestões de jogos que podem ser criados ou inventados, utilizando as cartas do UNO, para desenvolver as habilidades matemáticas deste estudante. O estudante possui 10 anos e está cursando o 3° ano do ensino fundamental."
```

## 📊 **Modelos de Atividades Adaptadas (COMPLETOS)**[^7]

### **Modelo 1 - Identificar palavras com S**

```
Versão adaptada:
"Observe as duas figuras abaixo.
Aponte, circule ou diga em voz alta.
Qual delas começa com o som da letra S?

[FIGURA SOL] vs [FIGURA BOLA]"
```


### **Modelo 2 - Classificação Água × Terra**

```
"Observe os animais abaixo.
Arraste, aponte ou diga onde cada um vive.

🌊 Vive na Água: Peixe, Golfinho
🐾 Vive na Terra: Cachorro, Gato"
```


### **Modelo 3 - Sequência de Rotina (3 Passos)**

```
"Organize na ordem em que acontecem de manhã:

Passo ___ Escovar os dentes
Passo ___ Tomar café
Passo ___ Colocar a mochila"
```


## 🔧 **Tecnologias Utilizadas nos Agentes**[^1]

- **LLM (Grandes Modelos de Linguagem)**: Geração de conteúdos pedagógicos personalizados
- **Python**: Programação do agente
- **Machine Learning**: Aprimoramento contínuo baseado em análise de dados da web
- **Ciência de Dados**: Análise preditiva e otimização do planejamento
- **Banco de Dados**: Currículo em Ação + Materiais Digitais + Currículo Paulista
- **Indicadores Didáticos e Pedagógicos**: Contexto escolar para adaptação


## 💡 **Como Aplicar no Projeto "IA para Atividades Adaptadas"**

1. **Use o Agente Adapton Educa** como base técnica (já calibrado com Currículo Paulista)
2. **Implemente prompts prontos** do Prof. Julio Passos para simplificação rápida
3. **Integre Livox** para comunicação alternativa de alunos não verbais
4. **Adote SEIA** para atividades com methodology ABA (Análise do Comportamento)
5. **Use ChatGPT/Gemini** com o "Prompt Mágico" para criar Funil Cognitivo
6. **Crie GEM personalizado** no Gemini para sua disciplina específica

## 📱 **Recursos Gratuitos Acessíveis**

- **NotebookLM**: Transforma PDFs em podcasts[^16][^17]
